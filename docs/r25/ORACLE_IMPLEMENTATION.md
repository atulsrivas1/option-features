[generate_r25_oracle.py](../../tools/generate_r25_oracle.py) uses exactly `mpmath==1.3.0`, with the pure Python backend selected before import. Official [1.3.0 differentiation documentation](https://mpmath.org/doc/1.3.0/calculus/differentiation.html), [error function documentation](https://mpmath.org/doc/1.3.0/functions/expintegrals.html) and [context documentation](https://mpmath.org/doc/1.3.0/contexts.html) establish the chosen API. These are specification references, not qualification evidence. The source uses no production package, production callback, production fixture values or Arb backend. Expected values are independent of the proposed production interval evaluator.

All supplied synthetic operands are bounded original rational strings; conversion parses integer numerator and denominator in each precision context. No input first passes through Python float. Each evaluation uses a separate 80 or 140 decimal digit context. Retain 65 significant digits only after the two results agree under `abs(low-high) <= 1e-60*max(abs(low),abs(high))`, with zero absolute allowance. Exact zero must agree exactly. This is a predeclared empirical oracle agreement budget, **not a rigorous rounding or transcendental error enclosure**. Tail outputs cannot pass this comparison by agreeing merely within an ordinary absolute price allowance. Underflow/cancellation that produces zero in both paths still requires independent review and additional tail fixtures before coverage is claimed.

The fixed inventory has 14 interior call/put examples and 18 separate symbolic endpoint examples. Interior examples cover nonzero carry, negative rate/carry, short/long time and unequal spot/strike. Price evaluates normal probabilities through `erfc`; closed Greeks use the algebraically distinct `erf` CDF path. Numerical derivatives of the independent price path check delta, gamma, vega, rho and annual negative-time theta under `1e-50` relative plus `1e-80` absolute allowance. At 140 digits, central spot differences at relative steps `1e-20` and `1e-25` check delta/gamma under `1e-35` relative plus `1e-65` absolute allowance. The larger allowance accommodates the fixed steps' second-order truncation; it is a secondary consistency probe, not the source of golden values or a certified bound. Put-call parity is checked separately under `1e-60` relative plus `1e-90` absolute allowance.

These exact rational mathematical examples are not yet production wire targets.
