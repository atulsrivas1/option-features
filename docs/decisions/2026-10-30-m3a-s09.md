# 2026-10-30: M3a S09 structural validation wrappers (design choices the rulings do not settle)

mock-data qualification only: passed on independently authored synthetic fixtures and synthetic workloads, Windows x64, CPython 3.12

Author: Developer (S09). Scope: `option_features/m3a_validate.py`. Each item is a choice the IO contract section 4 and R-01..R-188 leave open; reviewers may overturn any of them.

1. `validate="scanned"` and `"full"` give the same codes and both scan the whole chain once: every M3a output reads a frame built from every listed strike, so the contracts read are the chain (IO contract section 5: scanned is O(contracts read)).
2. Contract `style` (R-188, amends R-187): None or a non-string is `malformed_type` at position 10; an unknown string passes (contract reason `style_unknown` downstream). `condition` must be a string. `contract_id` must be a string (a non-string id is `malformed_type` at position 10, not checked at position 8).
3. Request fields without a value code are type-checked at position 10 only on outputs that use them: `evaluation_ns`, `feed_delay_tag` (in {live, delayed}), `stale_limit_ns`, `min_strikes`, `min_coverage` (int, Fraction, decimal or "a/b" text), `session_minutes`, `fire` (bool), `tail` (percentile outputs), `min_sessions`/`max_sessions` (history outputs), `pair` (V5), `prior_sessions`, `prior_kind` and `condition` (V10).
4. Selectors with a default (mode, lane, feed_delay_tag, delta_target, iv_form, delta_convention, direction): a supplied None is `malformed_type`; optional values (x, at_least, at_most, minute, prior, priors) treat None as not supplied.
5. Level thresholds `at_least`/`at_most`: non-bool int, Fraction or decimal text (float and Decimal are `malformed_type`, as the percentile `x`), type-checked at position 15; no range code.
6. Priors: `prior` (one) and `priors` (list) are both accepted on M3A-3, M3A-6, M3A-9; a prior's convention is read from `delta_convention`, else `convention`, else "spot". A prior without `time_ns` is not time-checked.
7. `delayed_feed_tag` applies to M3A-2 always and to intraday M3A-1, M3A-3, M3A-8 (V9 as V1, author2 V9-027). M3A-2 with mode "close" is `invalid_mode` (R-175, D7).
8. View read: a non-{spot, forward} `delta_convention` on a skew-type series is `malformed_type` at position 5 (no code in that list); skew-type = metric starting "skew", forward when it ends "_fwd".
9. M1 `ValueError` mapping (`m1_error_code`) is by message prefix of `chainiv.IVChain`; anything else is `malformed_type`.
10. Store entries (append, load, snapshot, text load) stay the M2 store's lists (R-70); `store_call` maps `M2StructuralError` to its code.
