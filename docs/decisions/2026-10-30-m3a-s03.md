# 2026-10-30: M3a S03 delta25 kernel, Developer choices

mock-data qualification only: passed on independently authored synthetic fixtures and synthetic workloads, Windows x64, CPython 3.12

Status: Developer choice (S03), for code and architecture review. The rulings R-04, R-05, R-09, R-10, R-16, R-21, R-74 and R-155 to R-157 settle the rule; they leave the following open.

1. Float filter with certified fallback (R-05 leaves it to the Developer, identical bytes required). Each visited strike gets a binary64 delta. Its side of 0.25 is trusted only when |d - 0.25| > 1e-6 and sigma sqrt(T) >= 1e-3. Otherwise the certified delta decides. The two bracket strikes always use the certified delta, because their values enter the interpolation. Spot uses `model.forward(..., "greeks.delta")`. Forward uses the same arb expression without the e^{-qT} factor, at the same tiers. `certified_only=True` runs the all-certified path, and the tests assert equal records on 240 randomized cases. Reason: M3A-B2. A certified delta costs about 0.2 ms, which would put about 12 strikes per point near the 2 ms budget.
2. Kernel input takes the ATM strike rather than the forward. The ATM rule (nearest the forward among strikes with both legs eligible, ties lower) stays in chainiv and S05, so it is not reimplemented here.
3. Excluded contracts: an IV of None (solver failure, R-109) is skipped and the scan continues over its neighbours. A strike whose certified delta is undefined (`Undefined` or `NumericalFailure` at every tier) is also skipped. This happens only at sigma 0 at the symbolic kink, and no fixture row reaches it. No new reason is added; the closed set is unchanged.
4. `evaluations` counts strikes visited (float or certified), one per strike. This is the M3A-B12 counter, and callers sum it per chain.

Measured counts on the author4 workloads: size S 59 to 60, size M 193 (budget 200, hard 400), size L 548 to 549 (no L budget). The first-crossing rule (R-10) needs every strike between ATM and the bracket. The count therefore equals the strike distance to the 25-delta strike and cannot drop further without changing R-10. Size M headroom is 7 evaluations (risk 2 of the build plan).
