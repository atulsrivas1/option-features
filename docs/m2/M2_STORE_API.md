# M2 store, grid builder and baseline modules: public API (story A)

mock-data qualification only: passed on independently authored synthetic fixtures and synthetic workloads, Windows x64, CPython 3.12

Author: Developer (story A), 2026-10-29. Status: Developer evidence only; the independent Tester must re-run. Story B (print-window families F1, F4, F7, F17, F18, F12) imports the shared helpers below; this file is the contract. Library modules only, not on the wire (no `variants1` change). All modules are pure, single-threaded, exact integer arithmetic; `Fraction` appears only in outputs and at decision boundaries that need it. Parallelism comes from the opt-in runner, never from the library (D4 amended).

## flowresult (shared by A and B)
- `REASONS = ("insufficient_history", "session_not_complete", "insufficient_window", "zero_denominator")`; `CODES` = the structural codes of the I/O contract section 2 plus `threshold_required`, `out_of_order_append`; `ALLOWED_WINDOWS = (60, 300, 900, 1800, 3600)`.
- `M2StructuralError(code, detail="")`: `ValueError` with `.code`. Raised by mutation APIs (`HistoryStore.append`, `flowgrid.window_totals`); kernels that return results never raise it, they return a `Result` with status `invalid_input`.
- `Result` (slots): `output_id, series_id, session_id, evaluation_ns, status, reason, code, value, fired, params, coverage, label, lane, per_statistic, parts_shown`. `value` is a dict of ints, `Fraction`s or None (exact; never float). `coverage` is a dict (`eligible_count, nonstandard_count, excluded_condition_count, unavailable_points`, or `{"degraded": True}`) or None. Constructors: `Result.available(...)`, `Result.unavailable(...)`, `Result.invalid(output_id, code, ...)`.
- `show(x)`: int for integral values, else reduced "n/d" string. `to_wire(result)`: dict in the contract key order (rationals shown, `per_statistic` and `parts_shown` placed after `label` only when set, `version` last). `canonical_line(result)`: compact JSON, no spaces, LF-free; `canonical_bytes(results)`: results sorted by (output_id, series_id, session_id, evaluation_ns), one per line, LF.

## flowgrid (shared by A and B)
- `Calendar(sessions)` with `sessions = [(session_id, minutes), ...]` ascending civil-date strings. `.ids`, `.minutes`, `.position(session_id)` (or None), `.minutes_of(session_id)`, `.extend(more)` (append only; never changes an earlier position).
- `Contract = namedtuple("Contract", "right strike expiry lane underlying")` (`right` "C" or "P", `strike` ticks int, `expiry` civil-date string, `lane` "stock" or "etf_index").
- Print (wire tuple): `(contract_id, time_ns, price, size, multiplier, condition_excluded, seq[, side])`; `price` is int ticks (price x 10^4) or a decimal string with at most 4 decimals (converted once); `side` is ignored. `price_ticks(price)`.
- `check_prints(prints)` returns the first structural code or None, precedence `unordered_prints` (order key (time_ns, seq)), `negative_size_or_price`, `bad_multiplier` (multiplier <= 0). `validate="full"` scans every print; `validate="scanned"` (hot-path default) checks only the prints it reads and relies on the documented precondition that the list is sorted by (time_ns, seq).
- Eligible print (shared definition for A and B): `multiplier == 100` and not `condition_excluded`, lane equal to the requested lane. Coverage counters: `excluded_condition_count` counts every in-window print with an excluded condition (also if nonstandard); `nonstandard_count` counts only non-excluded prints with multiplier != 100.
- `window_totals(prints, contracts, evaluation_ns, window_s, lane="stock", side_filter="all", validate="full")` -> `WindowTotals(premium, volume, count, put_volume, call_volume, eligible_count, nonstandard_count, excluded_condition_count)`; window closed at both ends [T-W, T]; premium in integer ticks (price ticks x size x multiplier); `side_filter` is "all", "calls" or "puts" (a plain right filter). Raises `M2StructuralError` for a bad print.
- `build_session_records(prints, contracts, session_id, open_ns, close_ns, minutes, windows=(300,), lane="stock", name_series_id=None, contract_series=True, validate="full")` -> `SessionBuild(records, eligible_count, nonstandard_count, excluded_condition_count)`; one pass over the prints with difference arrays (O(prints + series x minutes)). Grid point i is at `open_ns + 60 s x i` for `i in range(minutes)`; the stored value is the window-W value of the closed window [t_i - W, t_i] (AMB-4, AMB-8); the session total is the sum over eligible prints with `open_ns <= time_ns <= close_ns`. Name-level series (id `name_series_id`) carry all five metrics (`premium, contracts, prints, put_volume, call_volume`); contract-level series (id = contract id, created only for contracts with eligible prints) carry `premium, contracts, prints`. Records are `GridRecord`s ready for `HistoryStore.append_record`.

## flowstore
- `GridRecord = namedtuple("GridRecord", "series_id metric window_s session_id minutes idx vals total")`: sparse grid (`idx` ascending `array('H')`, `vals` `array('q')` or lists on 64-bit overflow, nonzero points only), `minutes` = grid length.
- `HistoryStore(calendar, k=20, strict_calendar=True)`: `k` retention (hard cap 60). Key = (series_id, metric, window_s); lane is fixed per key at first append.
  - `append(series_id, metric, window_s, session_id, grid, total=None, complete=True, grid_idx=None, lane="stock")`: dense `grid` list, or the nonzero values at `grid_idx` (strictly ascending, inside the grid). `total` defaults to `sum(grid)` (tests only; builders pass the session total). Errors (`M2StructuralError`, checked in this order): `session_not_in_calendar` (strict mode), then `duplicate_session` (equal to the key's last appended session) or `out_of_order_append` (earlier), then `non_monotone_grid`. Append past `k` evicts the oldest record (the ring counts every stored record, complete or not).
  - `append_record(record, complete=True, lane="stock")`: same checks, record already sparse (no copy).
  - `seal(series_id, metric, window_s, session_id)`: marks the record complete and immutable; returns False when no such record. A record appended with `complete=True` is born sealed.
  - `complete_sessions_before(series_id, metric, window_s, as_of, k=None)`: tuple of the last k complete stored sessions strictly before `as_of` (store form of "view as of a session", no look-ahead).
  - `baseline(series_id, metric, window_s, as_of, k=None, lane="stock")` -> `HistoryView` or None: the K calendar sessions immediately before `as_of`, all stored, all complete, same lane (no substitution, no partial baseline); None means `insufficient_history`. The view is immutable, hashable, cached per key until the ring changes.
  - `retained()`: `{"series|metric|window": [session ids]}` sorted. `lines()` / `dump()` / `dump_to(path)`: canonical serialization, one line per record in (series_id, metric, window_s, session_id) order, LF; key order `series_id, metric, session_id, window_s, grid, total, complete, content_sha256`; `content_sha256` = SHA-256 of the line without that field then LF (computed on demand, cached on the sealed record). `record_hashes()` = the per-record `content_sha256` list in canonical order; `content_hash()` = SHA-256 over every line plus LF. `HistoryStore.load(path_or_bytes, calendar, k=20)` reproduces the same bytes (M2-B17). `stats()`: series, records, estimated bytes, cache hits and misses (log only, never in a result).
- `HistoryView`: `series_id, metric, window_s, as_of, sessions, n` (grid points after dropping the first W/60 per session, AMB-4), `rank(x)` -> `(n, le, ge)` integer counts for an exact int or `Fraction` x, `median()`, `mean()` (exact `Fraction`), `totals`, `minutes`, `digest()`.

## flowrank (all take a store and return `Result`s; batched forms take an iterable of per-series inputs)
- `SessionInfo = namedtuple("SessionInfo", "session_id open_ns close_ns minutes complete feed_delay_tag total total_source")` (`total`, `total_source` None unless an end-of-day form needs them).
- `f2_rank(store, series_id, metric, x, session, evaluation_ns, window_s=300, form="intraday", X=5, K=20, lane="stock", coverage=None)`: F2a (`premium`), F2b (`contracts`), F2c (`prints`); `x` is the exact window quantity in grid units (premium ticks, contracts, print count; for the end-of-day form the session total); F2c converts to prints per minute only in the output. Gate order: structural, insufficient_history, session_not_complete (end-of-day), insufficient_window (intraday), then the value.
- `f2d_combine(a, b, c, window_s=300, X=5)`: three F2 results -> F2d (`fired` None, `parts_shown`, reason of the first unavailable part).
- `f10_baseline(store, series_id, x, session, evaluation_ns, window_s=300, N=2, K=20, consumer_default="median", lane="stock", coverage=None)`, `f20_baseline(store, series_id, metric, session, evaluation_ns, window_s=300, N=2, K=20, consumer_default="mean", lane="stock")`, `f19_percentile(store, series_id, put, call, session, evaluation_ns, window_s=300, X=5, K=20, lane="stock")` (`put`, `call` = today's session put and call volume; the prior ratios come from the stored `put_volume` and `call_volume` totals).
- `flow_pack(store, series_id, session, evaluation_ns, window_s, premium, volume, count, ...)`: F2a, F2b, F2c, F2d, F10 for one series from one shared gate evaluation and one view lookup per metric (a fused read; equal to the separate calls).
- `evaluate_many(...)`: batched over many series; equal to the one-at-a-time path, same order.
- Today-window inputs come from `flowgrid.window_totals` (or story B's one-pass families); both stories use the same eligible-print definition.
