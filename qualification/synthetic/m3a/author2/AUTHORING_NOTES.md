## 4. Row format
Dataset = one header line (calendars by reference, provenance SYNTHETIC, the label sentence, seed 20261030, row_count) then one JSON row per line, canonical key order, LF. Row keys: id, family, output_id, design_ref, ruling (R-numbers), tags, pending ("RULED" or "PENDING-RULING:Dn"), derivation, inputs, params, expected, optional alt_expected.
- Percentile rows (V1, V3, V9, units): inputs.records = [[calendar_index, value, complete01], ...] in append order (V3: [index, {base, over, len}, complete01], the dense minute grid with overrides); calendar_ref selects a header calendar (sessions with minute counts; V3 calendar: 30 minutes, every 17th session a 12-minute half-day; calendar gaps are skipped holiday dates); inputs.now = {"float": f} (V1, V3), {"put25_iv": f, "call25_iv": f} (V9: skew = difference of the UNROUNDED floats, rounded once, R-95) or {"unavailable": reason} (upstream M3A-0 or M3A-7 reason); inputs.ring_lane, lane, store_k (252), session {session_id, complete, feed_delay_tag}, cutoff_ns = evaluation_ns. Stored and compared values are integers in 10^-8 units.
- Expected carries only asserted keys: output_id, series_id, session_id, evaluation_ns, lane, status, reason, code, value, fired, and for available rows params (every parameter echoed with defaults) and labels. coverage is NOT asserted (see D12). x is the 8-decimal string; shares are ints or reduced "n/d".
- History rows: inputs.store_config {k_default, k_by_key}, ops (["s", series, metric, index, units, complete, lane] scalar, ["g", ...] minute grid with window_s 0, ["seal", ...]), query (scalar_baseline, same_minute_column, retained, hashes); expected is the logical read result.
- Tagged objects: X may be {"py_type": "Fraction", "text": "5/2"} or Decimal (m3a_common.decode); a harness must decode before the call.
- alt_expected = the answer under the other reading of a defect; a pending row passes with either only after the PO rules.
